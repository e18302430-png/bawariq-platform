# فيلم «مختفي» (قصة رومانسية بحبكة · 9:16 · 37 ثانية)

**الملف النهائي:** `munasabati-mukhtafi-9x16.mp4`. مقاسه 1080×1920، وترميزه H.264 Main 4.1.

## الحبكة
قبل الزواج بأسبوع يختفي خطيبها. يشوف رسايلها وما يرد، وتظهر «يكتب…» وبعدين تختفي. في رسايلها تزرع طلبين: «الورد الأبيض» و«جدتي أول وحدة تنعزم». ليلة الزواج تفتح الباب وتلقى الورد الأبيض في كل مكان، وجدتها في أول صف. وأخيراً يوصل رده: «كنت أجهز لك كل شي قلتيه»، وتحته كل طلباتها عليها صح، وبطاقة «جهّزتها عبر مناسبتي».

**الحيلة:** الجوال اللي حسبناه إهمال، طلع هو اللي جهز حلمها.

| الوقت | المشهد |
|---|---|
| 0–1.3 | «قبل الزواج بأسبوع…» |
| 1–10 | المحادثة: ٤ رسايل، وصلت ✓✓، يكتب… يختفي، «ولا رد.» |
| 10–17 | جرّبت فستانها لحالها، وأمها تقول اصبري (ألوان باردة) |
| 17–18.4 | «ليلة الزواج.» |
| 18.4–22.4 | الباب ينفتح على نور: «ورد أبيض… في كل مكان.» |
| 22.4–25.6 | الممشى: «وأول وحدة في الصف… جدتها.» |
| 25.6–32 | العريس، والجوال يهتز، ورده بالصح وبطاقة مناسبتي |
| 32–33.6 | يده بيدها: «كان مشغول… بحلمها.» |
| 33.6–37 | «خلّ المفاجأة علينا.» + الشعار + الرابط |
