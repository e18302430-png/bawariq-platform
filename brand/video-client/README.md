# فيديو مناسبتي للعميل (9:16 · 32 ثانية · موشن جرافيك)

**الملف النهائي:** `munasabati-client-9x16.mp4`
- 1080×1920، و30 إطار بالثانية، و960 إطار.
- الصورة: H.264، بصيغة yuv420p.
- الصوت: AAC بتردد 48 كيلوهرتز، وارتفاعه -16.2 LUFS، وأعلى قمة -2.1 dBFS.

## المشاهد والانتقالات (الإيقاع 120 نبضة بالدقيقة، يعني كل نبضة 0.5 ثانية)
| الوقت | المشهد | الانتقال |
|---|---|---|
| 0–2 | زواج؟ ملكة؟ تخرّج؟ عقيقة؟ (كلمة على كل نبضة) | قطع حاد على الإيقاع، والخلفية تتبدل |
| 2–4 | مناسبتك علينا. | ختم بارتداد + ومضة |
| 4–10 | ميزانيتك في دقيقة (بطاقة المساعد الحقيقية ترتفع) | مسحة مائلة بألوان البراند |
| 10–16 | اقتراحات على ذوقك (تمرير لصور القاعات) | انتقال سريع للجانب مع ضبابية حركة |
| 16–22 | دعوة لكل ضيف (الدعوة تنفتح بملء الشاشة) | دخول بالكاميرا داخل الجوال + لمعة ذهبية |
| 22–27 | رحلتك خطوة بخطوة | الدعوة ترجع داخل الجوال |
| 27–32 | ابدأ مناسبتك ببلاش + الرابط | مسحة مائلة + ضربة ختام |

كل الشاشات صور حقيقية من المنصة (`shots/`)، وفيها بيانات تجربة.

## المعاينة والتعديل
```bash
cd brand/video-client && python3 -m http.server 4311
```
افتح `http://localhost:4311`. تحت الصفحة: تشغيل، وإيقاف، وإعادة، وتنقل، وملء الشاشة، ورفع موسيقى أو شعار.

- **النصوص:** في `index.html`، داخل `WORDS` و`#stamp` و`#h2` … `#h5` و`#cta`.
- **الألوان:** في `:root`.
- **التوقيت:** في `S` و`WIPES` وأوقات الانتقالات داخل `render()`.
- **الموسيقى:** `audio/make_audio.py`، وتوقيتها مربوط بنفس الأوقات.

## إعادة التصدير
```bash
cd audio && python3 make_audio.py && ffmpeg -y -i mix.wav -af "alimiter=limit=0.6:attack=3:release=60:level=disabled,loudnorm=I=-14.5:TP=-2:LRA=11,aresample=192000,alimiter=limit=0.68:attack=1:release=50:level=disabled,aresample=48000" -c:a pcm_s16le mix_master.wav && ffmpeg -y -i mix_master.wav -c:a aac -b:a 192k mix.m4a && cd ..
```
```bash
python3 -m http.server 4311 &
```
```bash
node render.cjs
```
```bash
ffmpeg -y -framerate 30 -i frames/f%04d.jpg -i audio/mix_master.wav -map 0:v -map 1:a -c:v libx264 -profile:v high -preset slow -b:v 13M -maxrate 16M -bufsize 26M -pix_fmt yuv420p -r 30 -fps_mode cfr -c:a aac -b:a 192k -ar 48000 -movflags +faststart -t 32 munasabati-client-9x16.mp4
```
