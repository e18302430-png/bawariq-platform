# فيلم «سحر» (موشن جرافيك 9:16 · 32 ثانية)

**الملف النهائي:** `munasabati-magic-9x16.mp4`. مقاسه 1080×1920، و30 إطار بالثانية، وترميزه H.264 Main 4.1 يشتغل على كل الجوالات.

## السيناريو
آلاف ذرات الذهب تتشكل قدام العين وتحكي القصة، وكل شكل يتكون مع جرس:

| الوقت | الذرات تصير | النص |
|---|---|---|
| 0–2.6 | شرارة وحدة تلف بالظلام | عندك فكرة؟ |
| 2.6–5.2 | تنفجر وتكتب «فكرة» | قولها… بس. |
| 5.2–8.2 | خاتم بألماسة | زواج؟ خطوبة؟ (عقيقة · تخرّج · حفلة شركة) |
| 8.2–11.2 | بوابة قاعة وثريا | نجيب لك القاعة (عروض من قاعات الشرقية) |
| 11.2–14.2 | ظرف دعوة بختم قلب | نوصّل دعواتك (باسم كل ضيف) |
| 14.2–17.2 | كاميرا | ونرتّب الباقي (تصوير · ضيافة · كوشة) |
| 17.2–20.2 | درع وعلامة صح | وعربونك محفوظ (عبر المنصة) |
| 20.2–22.4 | كل شي ينكمش لنقطة نور، ثم صمت | وأنت؟ |
| 22.4–26.4 | انفجار ألوان، وبعده قلب | عيش ليلتك. |
| 26.4–32 | الذرات تبني شعار مناسبتي | من الفكرة لآخر ضيف + الرابط |

## التعديل
- **النصوص:** `CAPS` في `index.html`.
- **الأشكال وتوقيتها:** `MORPHS` و`buildShapes()`.
- **الصوت:** `audio/make_audio.py`. لو غيرت التوقيت، عدّل `MORPHS` فيه.

## التصدير
```bash
python3 -m http.server 4316
```
```bash
cd audio && python3 make_audio.py && cd .. && node render.cjs
```
```bash
ffmpeg -y -framerate 30 -i frames/f%04d.jpg -i audio/mix.wav -af "loudnorm=I=-14:TP=-2" -map 0:v -map 1:a -c:v libx264 -profile:v main -level:v 4.1 -preset slow -b:v 7M -maxrate 9M -bufsize 14M -pix_fmt yuv420p -r 30 -fps_mode cfr -g 60 -c:a aac -b:a 160k -ar 48000 -movflags +faststart -t 32 munasabati-magic-9x16.mp4
```
