# فيديو مناسبتي للقاعات (9:16 · 30 ثانية)

**الملف النهائي:** `munasabati-venues-9x16.mp4`
- 1080×1920، و30 إطار بالثانية ثابت.
- الصورة: H.264، بصيغة yuv420p، وحوالي 10 ميجابت بالثانية.
- الصوت: AAC بتردد 48 كيلوهرتز، وارتفاعه -16 LUFS، وأعلى قمة -1.6 dBFS.

## المشاهد (المصدر الوحيد للتوقيت: `CUES` في `index.html`)

| الوقت | العنوان | اللي يظهر |
|---|---|---|
| 0.0–4.6 | عندك ليالي فاضية بين الأسبوع؟ | تقويم بوابة القاعات الحقيقي |
| 4.6–9.6 | طلبات جاهزة توصلك | صندوق الطلبات + بطاقة الطلب مرفوعة |
| 9.6–14.6 | ترد بسعرك من جوالك | شاشة إرسال العرض + خانة السعر |
| 14.6–19.6 | حقك واضح ومضمون | شريط «سعرك · نسبة مناسبتي · حقك» |
| 19.6–25.2 | 0% من سعرك أول ٤ شهور | الرقم الكبير + «حسب خطة الإطلاق» |
| 25.2–30.0 | سجّل قاعتك اليوم | الشعار + الرابط + الشعار اللفظي |

كل الشاشات صور حقيقية من بوابة القاعات (`shots/`)، وفيها بيانات تجربة مكتوب جنبها «(مثال)».

## المعاينة
```bash
cd brand/video && python3 -m http.server 4310
```
افتح `http://localhost:4310`. تحت الصفحة تلقى الأدوات:
- تشغيل وإيقاف، ومن البداية، وشريط للتنقل، وملء الشاشة.
- رفع موسيقى أو شعار أو صور شاشات بديلة.

وفي وضع التسجيل (`?record`) تختفي كل الأدوات.

## التعديل
- **النصوص:** في `index.html`، داخل العناصر `#h1` … `#h4`، و`#zero`، و`#cta`.
- **الألوان:** المتغيرات في `:root` أول الملف.
- **التوقيت:** `CUES` (بداية ونهاية كل مشهد)، و`FOCUS` (وين تقرّب الكاميرا داخل الشاشة، وكم تكبّر).
- **الشاشات:** بدّل الصور في `shots/` بنفس الأسماء، أو ارفعها من زر «صور الشاشات» بالترتيب: تقويم، طلبات، عرض، حق. البطاقات المرفوعة هي `shots/lift-*.png`، وهي مقصوصة من الشاشات نفسها.
- **الصوت:** `audio/make_audio.py` يولّد الموسيقى والمؤثرات. وتوقيت المؤثرات فيه لازم يطابق `CUES`. لو غيرت التوقيت، شغّل:
  ```bash
  cd audio && python3 make_audio.py
  ```

## إعادة التصدير
```bash
cd brand/video && python3 -m http.server 4310 &
```
```bash
node render.cjs
```
```bash
ffmpeg -y -framerate 30 -i frames/f%04d.jpg -i audio/mix.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -map 0:v -map 1:a -c:v libx264 -profile:v high -preset slow -b:v 12M -maxrate 16M -bufsize 24M -pix_fmt yuv420p -r 30 -fps_mode cfr -c:a aac -b:a 192k -ar 48000 -movflags +faststart -t 30 munasabati-venues-9x16.mp4
```
`render.cjs` يحتاج Playwright ومعه Chromium.

## قبل النشر
- **«0% من سعرك أول ٤ شهور» صحيحة بس بعد ما تفعّل خطة الإطلاق** من لوحة الإدارة ← الإعدادات.
- **الموسيقى مولّدة بالكود**، مو مقطوعة مرخّصة. لو تبي موسيقى أقوى أو صوت ترند، حطها في CapCut أو ارفعها في المعاينة.
- **ما فيه تعليق صوتي.** لو سجلت صوت، نبني التوقيت عليه.
