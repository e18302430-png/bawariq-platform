# فيلم «ليلتي» (9:16 · 33 ثانية · موجّه للبنات)

**الملف النهائي:** `munasabati-lailati-9x16.mp4`
- 1080×1920، 30 إطار بالثانية.
- H.264 Main 4.1، ويشتغل على كل الجوالات.
- الموسيقى مولّدة بالكود في `audio/make_audio.py`.

## القصة والتعليق الصوتي (بصوت بنت، لهجة سعودية)
السطور تظهر على الشاشة بنفس التوقيت، فالفيديو يوصل الفكرة حتى لو الصوت مقفول.

| الوقت | المشهد | الجملة |
|---|---|---|
| 0.5–3.9 | يدين بالحنا على الفستان | كنت أحلم فيها من أنا صغيرة… |
| 4.6–7.9 | الأم وبنتها عند باب القاعة | الفستان، والكوشة… وأمي جنبي. |
| 8.6–12.4 | البنت بالليل، والإشعارات تتكدس، والقلب يدق | بس لما قرب اليوم… خفت. |
| 13.5–15.9 | سواد، ثم الشعار يولد من نور | لين جات مناسبتي. |
| 16.6–19.3 | دخول الرجال بالبشوت مع طبول الزفة | وليلة الزفة… ما شلت هم شي. |
| 19.8–22.2 | العريس بالبشت يعدّل شماغه | وهو هناك… ينتظرني. |
| 22.4–23.0 | صمت | — |
| 23.5–26.6 | العروس تمشي للكوشة، والورد يطيح | كنت بس… أعيش لحظتي. |

| 30–33 | الشعار + «من الفكرة لآخر ضيف» + الرابط | — |

## إضافة الصوت مجاناً
- **الأفضل:** بنت من العائلة تسجل السطور بالجوال (كل سطر لحاله، بهدوء وبإحساس).
- **أو CapCut:** حط الفيديو، واكتب كل سطر في «نص»، واضغط «تحويل النص إلى كلام» واختر صوت بنت عربي. CapCut يسمح باستخدام أصواته في محتوى تنشره من التطبيق.
- لو عندك ملف صوت `audio/voice.wav` بنفس التوقيت، هذا الأمر يدمجه ويخفض الموسيقى تحته تلقائياً:
```bash
ffmpeg -y -i munasabati-lailati-9x16.mp4 -i audio/voice.wav -filter_complex "[1:a]asplit[v1][v2];[0:a][v1]sidechaincompress=threshold=0.03:ratio=6:attack=20:release=400[m];[m][v2]amix=inputs=2:normalize=0,loudnorm=I=-14:TP=-2[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 160k munasabati-lailati-voice-9x16.mp4
```

## المعاينة والتصدير
```bash
python3 -m http.server 4315
```
افتح `http://localhost:4315`. ولإعادة التصدير:
```bash
cd audio && python3 make_audio.py && cd ..
```
```bash
node render.cjs
```
```bash
ffmpeg -y -framerate 30 -i frames/f%04d.jpg -i audio/mix.wav -af "loudnorm=I=-14:TP=-2" -map 0:v -map 1:a -c:v libx264 -profile:v main -level:v 4.1 -preset slow -b:v 7M -maxrate 9M -bufsize 14M -pix_fmt yuv420p -r 30 -fps_mode cfr -g 60 -c:a aac -b:a 160k -ar 48000 -movflags +faststart -t 33 munasabati-lailati-9x16.mp4
```
