# «من الفوضى… للباب»: فيديو مناسبتي للعميل (9:16 · 30 ثانية)

**الملف النهائي:** `munasabati-portal-9x16.mp4`
- 1080×1920، و30 إطار بالثانية، و900 إطار.
- الصورة: H.264، بصيغة yuv420p.
- الصوت: AAC بتردد 48 كيلوهرتز، وارتفاعه -15.8 LUFS، وأعلى قمة -2.5 dBFS.

## الفكرة
الشعار نفسه (الباب) هو الانتقال: كل مشهد ينفتح من داخل باب مناسبتي بحافة ذهبية.

| الوقت | المشهد |
|---|---|
| 0–4.8 | فوضى: رسائل تتكاثر وتتزاحم، ونبض يتسارع، وكلمات: «١٠ مكالمات · ٢٠ سعر · ليلة وحدة.» |
| 4.8 | تجمد: أبيض وأسود + صمت |
| 5.0–6.4 | الباب الذهبي يترسم، والرسائل تنسحب لداخله، و«مناسبتك علينا» |
| 6.4 | نطير من خلال الباب، ويبدأ الإيقاع (120 نبضة بالدقيقة) |
| 6.4–12.4 | ميزانيتك في دقيقة (بطاقة المساعد الحقيقية) |
| 12.4–18.4 | عروض حقيقية على ذوقك (بطاقتين حقيقيتين، وتنختار الأولى) |
| 18.4–23.4 | دعوة لكل ضيف (الدعوة تنفتح بلمعة ذهبية) |
| 23.4–27.4 | ليلتك تحت السيطرة (العد التنازلي) |
| 27.4–30 | الشعار + «مناسبتك علينا.» + الرابط |

- **الرسائل في الفوضى:** أمثلة توضيحية لضغط التجهيز، مو محادثات أشخاص حقيقيين.
- **شاشات المنصة:** صور حقيقية من المنصة، وفيها بيانات تجربة.

## المعاينة والتعديل
```bash
cd brand/video-portal && python3 -m http.server 4312
```
افتح `http://localhost:4312`.
- **الرسائل:** `MSGS`.
- **الكلمات الكبيرة:** `WORDS`.
- **التوقيت:** `T`.
- **مركز الباب وحجمه:** `CX` و`CY` و`U`.
- **الألوان:** في `:root`.
- **الصوت:** `audio/make_audio.py`، وتوقيته مربوط بنفس `T`.

