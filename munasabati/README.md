# مناسبتي

منصة المناسبات السعودية: أربعة تطبيقات مستقلة تشترك في نواة واحدة.

| التطبيق | المجلد | لمن |
|---|---|---|
| موقع مناسبتي | `apps/web` | صفحة الهبوط والتعريف بالبوابات الثلاث |
| تطبيق العميل | `apps/client` | أصحاب المناسبات: الترحيب الذكي، الضيوف، الدعوات، الميزانية، الضيافة، المهام، الحجوزات، استقبال الضيوف |
| بوابة الموردين | `apps/vendors` | مزودو الكوشة والتصوير والصوت والبث والضيافة والخيام والمولدات والاستيدج |
| بوابة القاعات | `apps/venues` | أصحاب القاعات وقصور الأفراح: القاعات والأقسام، أسعار الويكند، الإشغال، إغلاق الأيام |

كل تطبيق له دخوله وواجهته ويُبنى وينشر وحده. النواة المشتركة:

- `packages/core`: نموذج البيانات، العمليات (دوال نقية)، الحسابات، وطبقة المستودع، مع اختبارات آلية.
- `packages/ui`: نظام التصميم (الألوان والخطوط والمكونات والحرير اللوني الحي WebGL).

## التشغيل

```bash
npm install
npm run dev:web        # 5170
npm run dev:client     # 5171
npm run dev:vendors    # 5172
npm run dev:venues     # 5173
```

```bash
npm run typecheck   # TypeScript صارم
npm test            # اختبارات النواة
npm run build       # بناء التطبيقات الأربعة
npm run bundle:artifact   # تجميعها في مجلد واحد للعرض
```

عند النشر على نطاقات منفصلة، حدد الروابط بين التطبيقات: `VITE_HOME_URL`، `VITE_CLIENT_URL`، `VITE_VENDORS_URL`، `VITE_VENUES_URL`.

- **دراسة السوق:** `docs/COMPETITION.md`
