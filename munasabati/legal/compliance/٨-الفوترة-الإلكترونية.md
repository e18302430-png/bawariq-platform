# الفوترة الإلكترونية (فاتورة) — خطة مناسبتي
> الوضع: **المنشأة مسجّلة في ضريبة القيمة المضافة** (حسب جوابك). فكل مبلغ تستلمه مناسبتي يحتاج فاتورة إلكترونية متوافقة مع هيئة الزكاة والضريبة والجمارك.

## وش نفوتر؟ (دخل مناسبتي فقط)
| الخدمة | المشتري | نوع الفاتورة | ملاحظة |
|---|---|---|---|
| اشتراك القاعة (٣٩٩ ر.س/شهر) | منشأة | **فاتورة ضريبية** (B2B) | فيها الرقم الضريبي للقاعة إن وجد |
| رصيد عروض الموردين | منشأة | **فاتورة ضريبية** (B2B) | |
| باقات الدعوات | فرد | **فاتورة ضريبية مبسطة** (B2C) | |
| سعر القاعة/المورد نفسه | — | **ما نفوتره** | التاجر يصدر فاتورته للعميل مباشرة (هو البائع) |

## الأسعار والضريبة — ⚠️ قرار مطلوب
الأسعار المعلنة الحين (٣٩٩، ٣٩٠/٧٩٠/١٥٩٠، ١٤٩/٣٤٩/٦٩٩) **لازم تُعرض للمستهلك شاملة الضريبة ١٥٪**. اختر:
- **أ)** الأسعار الحالية شاملة الضريبة (يقل صافي دخلك ~١٣٪)، أو
- **ب)** نرفعها لتشمل الضريبة (٣٩٩ ← ٤٥٩ مثلاً).
وبعدها نكتب «شامل ضريبة القيمة المضافة» جنب كل سعر.

## محتوى الفاتورة (المرحلة الثانية: الربط والتكامل)
- اسم المنشأة، العنوان، **الرقم الضريبي**، السجل التجاري
- رقم فاتورة متسلسل، UUID، تاريخ ووقت الإصدار
- وصف الخدمة، المبلغ قبل الضريبة، **الضريبة ١٥٪**، الإجمالي
- **رمز QR** (صيغة TLV حسب مواصفات الهيئة) وختم تشفيري
- B2B: اسم المشتري ورقمه الضريبي وعنوانه
- إرسال للهيئة: المبسطة خلال ٢٤ ساعة (Reporting)، والضريبية قبل التسليم (Clearance)
> **لا نبني محرك الفوترة بأنفسنا**: الختم التشفيري والربط مع منصة فاتورة لازم يكون عبر حل معتمد.

## مزودون للمقارنة (تأكد من القائمة الرسمية للحلول المعتمدة على موقع الهيئة zatca.gov.sa قبل التعاقد)
| المزود | ربط برمجي (API) | مناسب لـ | ملاحظات |
|---|---|---|---|
| وافق Wafeq | نعم | شركات ناشئة، اشتراكات | محاسبة + فوترة، API موثّق |
| قيود Qoyod | نعم | منشآت صغيرة ومتوسطة | محاسبة سحابية سعودية |
| دفترة Daftra | نعم | منشآت صغيرة | فوترة ومحاسبة |
| Zoho Books (السعودية) | نعم | لو تبي نظام عالمي | يدعم متطلبات فاتورة |
| بوابة الدفع (ميسر/Tap) + مزود فوترة | — | لو فعّلنا الدفع الإلكتروني | البوابة ما تغني عن الفاتورة |

**معايير الاختيار:** معتمد من الهيئة للمرحلة الثانية · API لإصدار فاتورة تلقائياً عند تأكيد الدفع · دعم المبسطة والضريبية · السعر الشهري · دعم عربي.

## التنفيذ في المنصة (بعد اختيار المزود ومفتاح الـ API)
1. لما الإدارة تأكد استلام تحويل (اشتراك/رصيد/باقة) → دالة خادم تنادي API المزود وتصدر الفاتورة.
2. نحفظ رقم الفاتورة ورابط الـ PDF مع الطلب، ويظهر للتاجر/العميل زر «الفاتورة».
3. الإلغاء والاسترداد → **إشعار دائن** عبر نفس المزود.
4. مفتاح الـ API يُحفظ كسرّ في الخادم، ما يوصل للمتصفح.

## يراجعه محاسب/محامٍ
- موعد موجة الربط الخاصة بمنشأتك (الهيئة تبلّغ كل منشأة بموعدها حسب الإيرادات)
- معاملة الرصيد غير المستخدم للموردين ضريبياً (دفعة مقدمة؟)
- الفترة التجريبية المجانية (٩٠ يوم) والعروض
