# تشغيل مناسبتي على Vercel

قاعدة البيانات **جاهزة ومربوطة** (مشروع Supabase «munasabati» في منظمة Bawariq Al Sharq، منطقة فرانكفورت):
- الجداول وسياسات الحماية (RLS) ودوال شاشة المنسق مُنفّذة.
- الدخول السريع بالاسم والجوال مفعّل.
- حساب الإدارة جاهز ببريد المالك وصلاحية admin.
- عنوان قاعدة البيانات والمفتاح العام محفوظان في `.env.production` (المفتاح العام آمن للمتصفح، والحماية بسياسات قاعدة البيانات).

## النشر (مرة وحدة، دقيقتين)
1. ادخل vercel.com بحساب GitHub.
2. **Add New → Project** واختر المستودع `bawariq-platform`.
3. **Root Directory**: اختر `munasabati`. باقي الإعدادات تُقرأ تلقائياً من `vercel.json`.
4. **Deploy**.

بعدها كل تعديل يندفع على GitHub ينشر نفسه تلقائياً.

## الروابط بعد النشر
| الصفحة | الرابط |
|---|---|
| صفحة الترحيب | `/` |
| تطبيق العميل | `/client/` |
| بوابة الموردين | `/vendors/` |
| بوابة القاعات | `/venues/` |
| الإدارة (مخفية) | `/admin/` بالبريد وكلمة المرور |

## لاحقاً
- **رسائل SMS للدخول**: اربط مزود رسائل من Supabase ← Authentication ← Providers ← Phone، ثم أضف في Vercel متغير `VITE_AUTH_MODE=phone`.
- **نطاق خاص** (مثل munasabati.sa): من Vercel ← Settings ← Domains.

## للمطورين
- `npm run build`: نسخة الإنتاج المربوطة بقاعدة البيانات.
- `npm run build:demo`: نسخة التجربة داخل المتصفح (بدون قاعدة بيانات).
- `supabase/schema.sql`: المخطط الكامل (آمن لإعادة التشغيل). `supabase/seed.sql`: أمثلة اختيارية.

## إبقاء قاعدة البيانات نشطة (تلقائي)
Supabase المجاني يوقف المشروع إذا ما فيه نشاط أسبوع كامل. لذلك فيه مهمة يومية على Vercel (`api/keepalive.mjs` و`crons` في `vercel.json`) تشتغل كل يوم الساعة ٦ صباحاً بتوقيت UTC (٩ صباحاً بتوقيت السعودية) وتقرأ من قاعدة البيانات طلباً خفيفاً. تقدر تتأكد منها من Vercel ← المشروع ← Settings ← Cron Jobs، أو بفتح `/api/keepalive`.
