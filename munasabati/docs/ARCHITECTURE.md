# البنية التقنية

## المبادئ

1. **فصل كامل بين الأطراف.** العميل والمورد وصاحب القاعة لكل منهم تطبيق مستقل (build ونشر ودخول مستقل). لا يستورد تطبيق من تطبيق آخر.
2. **نواة واحدة للمنطق.** كل قواعد العمل (التسعير، الضيافة، المطابقة، رحلة الحجز، بوابة الدخول) في `packages/core` كدوال نقية بلا واجهة، ومغطاة باختبارات.
3. **واجهة بيانات قابلة للاستبدال.** التطبيقات تتعامل مع `Repository` فقط. التنفيذ الحالي يحفظ في المتصفح للعرض، والتحويل لخادم حقيقي يتم في ملف واحد.
4. **نظام تصميم موحد.** `packages/ui` يحمل الألوان (نهاري وليلي) والخطوط والمكونات، فكل البوابات تبدو كمنتج واحد.

## التقنيات

| الطبقة | الاختيار | السبب |
|---|---|---|
| اللغة | TypeScript بوضع strict | أخطاء أقل، وعقود واضحة بين الحزم |
| الواجهة | React 18 | أكبر منظومة وأسهل توظيف |
| البناء | Vite 5 | بناء سريع وتقسيم الحزم |
| الحركة | Framer Motion | حركات فيزيائية (spring) وانتقالات مشتركة |
| الرسوميات | WebGL (Shader مخصص) | الحرير اللوني الحي بدون مكتبات ثقيلة |
| الاختبارات | Vitest | اختبار النواة بسرعة |
| المستودع | npm workspaces | Monorepo بحزم مشتركة |

## تدفق البيانات

```
تطبيق العميل ──createBooking──▶ Repository ◀──setBookingStatus── بوابة المورد / القاعة
       ▲                              │
       └──────── subscribe ───────────┘   (تحديث لحظي، ومزامنة بين النوافذ عبر storage events)
```

العمليات في `core/db.ts` كلها من نوع `Mutation = (db) => db`، فيمكن تطبيقها محلياً أو إرسالها لخادم.

## الانتقال للإنتاج

1. **قاعدة البيانات:** Supabase (Postgres) بجداول: `clients`, `events`, `guests`, `suppliers`, `venues`, `halls`, `bookings`, `messages`، مع Row Level Security لفصل بيانات كل طرف.
2. **المستودع:** تنفيذ `SupabaseRepository` بنفس واجهة `Repository`.
3. **الدخول:** OTP على الجوال (Supabase Auth أو Unifonic)، وأدوار: client / supplier / venue_owner / admin.
4. **الواتساب:** WhatsApp Business API لإرسال الدعوات والتذكيرات واستقبال الردود.
5. **الدفع والفوترة:** بوابة مرخصة (ميسر أو تاب) وفوترة متوافقة مع هيئة الزكاة والضريبة والجمارك.
6. **تطبيق جوال للبوابة:** React Native لمسح QR بالكاميرا عند الباب.
7. **الاستضافة:** كل تطبيق على نطاق فرعي (app. / vendors. / venues.) مع استضافة البيانات داخل المملكة حسب نظام حماية البيانات الشخصية.
