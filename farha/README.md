# فرحة: منصة المناسبات السعودية

نظام متكامل لتخطيط المناسبات وحجز القاعات وخدمات التجهيز، بثلاث واجهات:

| الواجهة | الرابط | المحتوى |
|---|---|---|
| صفحة الترحيب | `#home` | كلمة من ضوء تتفاعل مع المؤشر، ومساعد ذكي يبني خطة المناسبة خلال دقيقة (ميزانية، ضيافة، قاعات مطابقة)، وبطاقة دعوة ثلاثية الأبعاد |
| لوحة العميل | `#my` | عد تنازلي، الضيوف (قسم رجال ونساء)، الدعوات بالواتساب ورموز QR، الميزانية والدفعات، حاسبة الضيافة، مهام العائلة، الحجوزات، ووضع يوم المناسبة (مسح الدخول) |
| السوق | `#explore` و `#venue-<id>` | القاعات والمزودون بالفلاتر، وصفحة تفاصيل بالباقات وتقويم التوفر وطلب الحجز |
| بوابة التاجر | `#vendor` | تسجيل نشاط جديد أو دخول تجريبي، لوحة الإيرادات، صندوق الطلبات وعروض الأسعار، التقويم، الباقات، الملف التعريفي، والاشتراك |
| دراسة السوق | `#study` | المنافسون والفجوات ونموذج الإيرادات وخطة الدخول |
| صفحة الضيف | `#invite-<code>` | الدعوة كما يراها الضيف مع تأكيد الحضور |

طلب الحجز من العميل يوصل فعلياً لصندوق التاجر، ورد التاجر بعرض سعر يظهر في لوحة العميل.

## التشغيل

```bash
cd farha
npm install
npm run dev
```

- `npm run build`: بناء عادي في `dist/` (للنشر على Vercel أو أي استضافة)
- `npm run build:single`: ملف HTML واحد في `dist-single/`

## الوضع الحالي

هذه نسخة أولى كاملة الواجهات، والبيانات تُحفظ في متصفح المستخدم (localStorage). كل الأسماء والأسعار أمثلة. منطق البيانات معزول في `src/store.jsx` حتى يُستبدل بقاعدة بيانات حقيقية بدون تغيير الواجهات.

قبل الإطلاق التجاري: خادم وقاعدة بيانات (Supabase)، دخول OTP، WhatsApp Business API، بوابة دفع، فوترة متوافقة مع هيئة الزكاة، وتطبيق جوال لمسح QR بالكاميرا. التفاصيل في `docs/COMPETITION.md`.
